# Email System

A beginner Python project completed as part of the freeCodeCamp Python Certification course.

# Description

A simple email system that allows users to send, receive, read, check, and delete emails.

# Concepts Used

- Classes and objects
- Multiple interacting classes
- Methods
- Lists
- Conditional statements
- `datetime`
- `__str__()` method
- Object composition

# Features

- Send emails between users
- Store emails in an inbox
- View inbox
- Read emails
- Mark emails as read
- Delete emails
- Display email timestamps
